# 2026-10-13 — Separate dashboard history inspection from control focus

The owner selected a screen-local inspection contract after a Codex creature
showed a detail card without the expected timeline list. Apple MonitorScreen and
Android LCD/e-ink screens now own their history filter independently of daemon
`focusedSessionId`. Creature/session-row selection and filter clear do not send
`focus_session`; explicit answers and deck/menu-bar control selection retain their
existing target semantics. The contract is in [docs/protocol.md](docs/protocol.md).

Folded Codex rows include their declared member IDs. The shared observed-ID
normalizer now accepts Swift `codex:` IDs, with generated Swift/Kotlin mirrors;
Node and Swift history lookups normalize both stored and requested IDs. Changing
a timeline filter resets selection and scroll to the newest matching record.
Android native 3D uses projected resident bounds for creature taps.

Swift acceptance replay, not by user work or a production discovery loop. Its
receipt recorded successful roster cleanup at 2026-10-12T23:58:39Z; labeled test
timeline evidence is intentionally retained. The runner now refuses before any
network request unless `--allow-visible-fixtures` is explicit, and testing docs
recommend an isolated app/data store. A regression test exercises the refusal.
